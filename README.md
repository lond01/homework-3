# 🎮 Камінь, ножиці, папір

Проста консольна гра **«Камінь, ножиці, папір»**, написана на Python.

Гравець грає проти комп'ютера. У кожному раунді комп'ютер випадково обирає камінь, ножиці або папір, після чого визначається переможець.

## 🕹️ Як грати

Запусти файл `main.py` та введи один із варіантів:

* `камінь`
* `ножиці`
* `папір`

Щоб завершити гру, введи:

```text
вихід
```

## ✨ Можливості

* 🎲 Випадковий вибір комп'ютера
* 🏆 Визначення переможця
* 📊 Підрахунок перемог, поразок і нічиїх
* 🔄 Можливість грати багато раундів
* ❌ Перевірка неправильного введення
* 🚪 Можливість завершити гру командою `вихід`

## 🛠️ Використані технології

* 🐍 Python
* `random.choice()`
* `if / elif / else`
* `while`
* `input()`
* змінні та списки

## 🚀 Запуск

1. Завантаж репозиторій.
2. Відкрий папку проєкту.
3. Запусти:

```bash
python main.py
```
